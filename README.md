## Overview

Designed with precision and crafted for impact, this portfolio showcases the software engineering work, interactive projects, and technical competencies of **Jeswin Karunya Benedict**. 

Built using Next.js 16, React 19, TypeScript, and Tailwind CSS, the platform delivers a fluid user experience featuring dynamic theme switching, micro-animations, and a Neo-Brutalist design language.

## Quick Start

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/jeswinbenedict/portfolio.git

# Navigate to the project root
cd portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
